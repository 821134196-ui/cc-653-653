# 港口岸电接入计时与船舶结算系统

船舶在不同泊位接电、途中可能停电。系统按**真实接电区间（计量段）**出账，船方逐段核对用电量、费率、服务时长与原始读数；异常读数暂停结算，补录双人复核；异议全程留痕、原账单不可变。

## 技术栈

- 后端：Go 1.23 + Gin + GORM + SQLite（纯 Go 驱动 modernc，无需 CGO）
- 前端：Vue 3 + Vite（单页应用，生产模式由 Go 单端口托管）
- 本地模拟：虚拟电表设备（手动/自动回传、序列号重放）+ 模拟付款回执

## 一条命令启动

```bash
./run.sh        # 生产模式：构建前端，Go 在 http://localhost:8080 单端口提供页面+API
./run.sh dev    # 开发模式：后端 :8080，Vite 热更新 :5173（/api 自动代理）
```

首次运行自动建表并写入种子数据（4 个泊位/电表、3 个岗位账号）。
环境变量：`SP_ADDR`（监听地址，默认 :8080）、`SP_DB`（SQLite 路径，默认 backend/data/shorepower.db）。

> 若机器上没有 Go，脚本会自动使用 `~/go-sdk/go`（本仓库即按此安装）。

## 核心业务规则

### 1. 计量段 = 真实接电区间
- 一次接电（`Connection`）由 1..N 个**计量段**（`MeterSegment`）组成。
- **换泊位**：原段在换泊位时刻截止（留下止码），新泊位电表开新段；每段出账时**按该段泊位锁定费率快照**（A 区 1.20 元/kWh＋8 元/h，B 区高压 1.55 元/kWh＋12 元/h）。
- **停电**：停电开始即截止当前段；停电窗口不属于任何计量段，**不计服务时长**，窗口内设备回传标记 `excluded/during_outage` 留存但不采信；恢复供电另起新段。
- 每段金额 = (止码−起码) × 该泊位电价 ＋ 段时长 × 该泊位服务费。

### 2. 原始读数是证据，永不物理删除/就地改写
- 设备读数带单调 `device_seq`，`(meter_code, device_seq)` 数据库唯一约束兜底。
- **重复回传**：同序列号再传（无论数值/时间）只对原记录累加 `dup_count`，绝不产生第二条计费数据。
- 校验四类异常：**读数倒退**（小于上一条采信值）、**异常跃升**（折算平均功率超电表上限 200/500kW）、**漏报**（序列号跳号）、**时间倒序**。
- 异常读数 `flagged` 入库留证，同时接电单进入 **billing_hold 挂起**：换泊位/停电/结束/出账全部暂停。
- 复核员对异常给出"采信/剔除"结论；记录转为 `accepted/rejected` 但**行不删除**，处置人、时间、依据都留痕。

### 3. 漏报补录必须双人复核
- 值班员补录 → 状态 `pending_review` 且账单挂起；
- **不能自录自审**（同账号复核返回 403），须另一岗位账号通过/驳回；
- 补录时间必须落在某计量段内（落停电窗口直接拒绝），数值不得低于段起码。

### 4. 账单不可变，异议走调整单
- 接电结束且无挂起事项才能出账；同一接电单**只能出一次账**。
- 账单逐段列出：泊位/电表、服务区间、起止表码、电量、时长、电价、服务费、金额，并保存出账时全部段/读数/停电记录的 JSON 快照，页面可直接查看。
- 流程：生成 → 船方确认 → 模拟付款（按调整单净额生成回执）。
- 船方提出异议后账单冻结为 `disputed`（禁付款）；原账单、快照、证据、异议理由全部保留。复核岗结论为"维持原账 / 退款冲减 / 补收差额"，后两者生成 **CreditNote 调整单**，原账单金额永不变化，付款按净额结算。

## 页面说明

1. **接电作业**：登记接电；读数上报；换泊位/停电/恢复/结束表单；计量段时间线与每段"查看原始读数"；出账。
2. **读数 · 异常复核 · 设备模拟**：设备手动/自动回传、一键制造倒退与跃升、按序列号重放；补录提交与双人复核；异常采信/剔除；全量读数台账（含重复计数、停电窗口排除标记）。
3. **账单与付款**：逐段费用、原始读数 JSON 快照、调整单、模拟付款回执、船方确认/异议。
4. **异议处理**：复核岗登记结论，成立时开调整单。

## 接口一览（/api）

```
GET  /meta                                  泊位/电表/用户
POST /connections                           登记接电(船名,电表,起始读数)
POST /connections/:id/change-berth          换泊位(原止码,新表,新起码)
POST /connections/:id/outage | /resume      停电开始 / 恢复
POST /connections/:id/close                 结束接电
POST /connections/:id/readings              人工读数
POST /connections/:id/supplement            漏报补录(待复核)
POST /connections/:id/bill                  生成账单
POST /devices/readings                      设备回传(可带 device_seq)
POST /readings/:id/review                   补录双人复核
POST /readings/:id/resolve                  异常读数采信/剔除
POST /readings/:id/replay                   按原序列号重放(验重复回传)
GET  /bills | /bills/:id                    账单列表/详情(含快照,调整单,回执)
POST /bills/:id/confirm | /pay | /dispute   船方确认/模拟付款/异议
GET  /disputes; POST /disputes/:id/resolve  异议列表/结论+调整单
GET  /sim/status; POST /sim/auto            设备模拟器状态/自动回传开关
```

## 验证

### 单元/集成测试（8 个场景）

```bash
cd backend && go test ./... -v
```

覆盖：换泊位分段费率、停电区间剔除、倒退挂起→处置放行、异常跃升、漏报补录双人复核（自审被拒）、重复回传幂等、异议冻结+调整单净额付款、禁止重复出账。

### HTTP 端到端（37 项断言）

```bash
# 终端1：启动一个临时服务
SP_ADDR=:18080 SP_DB=/tmp/sp-e2e.db SP_FRONTEND_DIST=frontend/dist ./run.sh
# 终端2：
node scripts/e2e.mjs
```

最近一次结果：**37 通过 / 0 失败**，含：
- 换泊位：A1 段 20kWh×1.20＋2h×8 = **40 元**；B1 段 40kWh×1.55＋2h×12 = **86 元**，合计 126；
- 倒退读数：结束接电/出账均 409，值班员处置 403，复核员剔除后放行且记录仍在；
- 重复回传：同 seq 重发两次，采信读数不增加、`dup_count=2`、电量不变；
- 异议：退 10 元后原账单仍为 126，模拟付款回执实付 **116**。
